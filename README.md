# Enterprise Customer Churn & Revenue Risk Predictor 📊

An end-to-end Machine Learning web application that predicts customer churn risk and calculates potential annual revenue at risk for subscription-based businesses.

## Features
- **Data Preprocessing & Encoding**: Cleaned categorical feature set for model ingestion.
- **ML Model Benchmark**: Trained and evaluated Logistic Regression, Random Forest, and XGBoost classifiers.
- **Best Model Selection**: Saved Logistic Regression model achieving **0.7935 ROC-AUC**.
- **Interactive Streamlit Dashboard**: Real-time churn probability estimation and revenue loss quantification.

## Tech Stack
- **Python 3**
- **Pandas, NumPy**
- **Scikit-Learn, XGBoost**
- **Streamlit**
- **Joblib**
